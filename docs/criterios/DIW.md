**Profesor:** Vicente Payá Tamayo, v.payatamayo@edu.gva.es, atención lunes 18:00-18:45
**Fuente:** presentación del curso (`originales/DIW-criterios.pdf`)

## Datos del módulo
- **133 horas**, 4 h/semana. Legislación: RD 686/2010, RD 405/2023, RD 500/2024, Decreto 117/2025.
- Septiembre y junio: lunes 16:30-18:00 y viernes 19:50-21:20. Horario normal: lunes 15:30-17:20 y viernes 18:35-20:25.

## Asistencia
- Obligatoria. **Mínimo 85 % de las horas del módulo**; si no, pérdida del derecho a evaluación continua.

## Evaluación
- **60 % exámenes** teórico-prácticos (problemas, supuestos, desarrollo corto, test).
- **40 % ejercicios** de clase/casa (observación diaria, casos prácticos, entregas en plazo, exposición).
- Por unidad didáctica: 60/40. **Imprescindible aprobar cada una de las partes** y cada unidad para aprobar la evaluación.
- Tres evaluaciones. 1ª: media de las UD. **Final: 7 % UD1 + 7 % UD2 + 20 % UD3 + 10 % UD4 + 6 % UD5 + 20 % UD6 + 20 % UD7 + 10 % UD8**, sin decimales.

## Actividades
- Todas obligatorias y en plazo. Fuera de plazo = 0. **Actividad no entregada = unidad suspendida.**
- Para optar a cualquier evaluación hay que haber entregado TODAS las actividades, incluso atrasadas.
- Copiar = 0 sin recuperación → suspenso de la asignatura.

## Recuperación
- Recuperaciones de unidades suspendidas en mayo. Con alguna UD suspendida → extraordinaria en junio con los RA suspendidos.

## Unidades
1. Principios de diseño gráfico para la web, 2. HTML5 y CSS3, 3. CSS avanzado, 4. Introducción a JavaScript, 5. Interfaces gráficas y UX, 6. Sass, 7. Bootstrap, 8. Tailwind

## Resultados de aprendizaje
1. Planifica interfaces aplicando especificaciones de diseño. 2. Crea interfaces homogéneas con estilos. 3. Prepara multimedia para la web. 4. Integra multimedia e interactividad. 5. Interfaces accesibles. 6. Interfaces usables.
